## Git 저장소 포함 정책

시연영상 원본 파일은 용량이 약 115MB로, GitHub 일반 Git 파일 제한인 100MiB를 초과할 수 있어 저장소에는 직접 포함하지 않는다.

대신 산출물 Google Drive에 업로드된 영상을 공식 제출본으로 사용하고, Git 저장소에는 본 문서로 접근 링크와 제출 정보를 남긴다.

## 확인 사항

- Google Drive 공유 설정 확인 필요: 링크가 있는 사용자가 열람 가능
- 제출용 산출물 시트에는 위 Google Drive 링크 사용
- 영상 원본 파일은 Git commit 대상에서 제외
